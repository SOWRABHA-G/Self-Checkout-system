# AI Powered Self Checkout System

## Overview
This project is an AI-powered self checkout system developed using Python, OpenCV, and TensorFlow.

## Technologies Used
- Python
- OpenCV
- TensorFlow
- CNN

## Features
- Real-time product detection
- Smart checkout system
- Fraud detection support
- Automated billing assistance

## Project Files
- mini.py
- coco.names
- frozen_inference_graph.pb
- SSD MobileNet model files

## How to Run

1. Install dependencies:
   pip install opencv-python numpy

2. Keep all model files in the same folder

3. Run:
   python mini.py

## Output
The system automatically detects products and performs intelligent checkout operations.
